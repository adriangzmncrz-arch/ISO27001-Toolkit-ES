# Glosario

Definiciones de trabajo usadas en el toolkit. Para las definiciones normativas consulta ISO/IEC 27000.

| Término | Definición |
|---|---|
| **Activo de información** | Todo lo que tiene valor para la organización y contiene, procesa o soporta información: datos, sistemas, equipos, personas, instalaciones, servicios. |
| **Acción correctiva** | Acción para eliminar la causa de una no conformidad y evitar que vuelva a ocurrir. |
| **Alcance** | Límites del SGSI: qué procesos, sedes, sistemas y personas cubre. |
| **Amenaza** | Causa potencial de un incidente que puede dañar a un activo o a la organización. |
| **Apetito de riesgo** | Nivel de riesgo que la dirección está dispuesta a aceptar en la búsqueda de sus objetivos. |
| **ARCO** | Derechos de Acceso, Rectificación, Cancelación y Oposición del titular de datos personales (México). |
| **Confidencialidad** | Propiedad de que la información no esté disponible ni se divulgue a personas, entidades o procesos no autorizados. |
| **Control** | Medida que mantiene o modifica un riesgo. |
| **Disponibilidad** | Propiedad de ser accesible y utilizable cuando lo requiere una entidad autorizada. |
| **Evento de seguridad** | Ocurrencia que indica una posible violación de la seguridad o la falla de un control. No todo evento es un incidente. |
| **Hallazgo** | Resultado de evaluar la evidencia de auditoría frente a los criterios: conformidad, no conformidad, observación u oportunidad de mejora. |
| **Impacto** | Consecuencia de un incidente sobre los objetivos de la organización. |
| **Incidente de seguridad** | Uno o varios eventos no deseados con probabilidad significativa de comprometer las operaciones o amenazar la seguridad de la información. |
| **Información documentada** | Información que la organización debe controlar y mantener, junto con el medio que la contiene. Incluye documentos (que se actualizan) y registros (evidencia que no se modifica). |
| **Integridad** | Propiedad de exactitud y completitud de la información. |
| **LFPDPPP** | Ley Federal de Protección de Datos Personales en Posesión de los Particulares (México), nueva ley publicada en el DOF el 20 de marzo de 2025. |
| **MFA** | Autenticación multifactor: uso de dos o más factores (algo que sabes, tienes o eres) para verificar la identidad. |
| **No conformidad** | Incumplimiento de un requisito de la norma, de un requisito legal o de lo que la propia organización estableció. Puede ser mayor o menor. |
| **Partes interesadas** | Personas u organizaciones que pueden afectar, verse afectadas o percibirse afectadas por las decisiones de la organización. |
| **Propietario del activo** | Persona o rol responsable de un activo durante su ciclo de vida, incluida su clasificación y la autorización de accesos. |
| **Propietario del riesgo** | Persona o rol con la responsabilidad y autoridad para gestionar un riesgo. |
| **Riesgo inherente** | Nivel de riesgo antes de aplicar nuevos controles de tratamiento. |
| **Riesgo residual** | Riesgo que permanece después del tratamiento. |
| **RPO** | *Recovery Point Objective*: pérdida máxima de datos tolerable, expresada en tiempo. |
| **RTO** | *Recovery Time Objective*: tiempo máximo tolerable para restablecer un servicio. |
| **SGSI** | Sistema de Gestión de Seguridad de la Información. |
| **SoA** | *Statement of Applicability*, Declaración de Aplicabilidad: documento que lista los controles del Anexo A, indica si son aplicables, justifica la decisión y señala su estado de implementación. |
| **Vulnerabilidad** | Debilidad de un activo o control que puede ser aprovechada por una amenaza. |
